# Анализ продаж фармацевтической компании по территориям, брендам и командам продаж.
О проекте
Данный проект представляет собой интерактивный аналитический дашборд, разработанный в Power BI для анализа продаж фармацевтической компании. Инструмент ориентирован на региональных менеджеров и директоров по маркетингу, позволяя в реальном времени оценивать эффективность работы медицинских представителей, анализировать продажи по территориям, брендам и командам. Для наполнения дашборда использованы синтетические данные, которые имитируют реальные бизнес-процессы. 

Задача: Визуализация и анализ продаж по территориям, брендам и командам медицинских представителей.

Реализация: Построение модели данных в Power BI, написание мер на языке DAX, создание интерактивных отчетов с возможностью фильтрации.

Результат: Создан инструмент, позволяющий руководству быстро оценивать эффективность полевых сил (field force) и принимать решения на основе данных (data-driven decisions).

Ключевые возможности дашборда:

Анализ по территориям: Сравнение показателей продаж в разных регионах, выявление лидеров и отстающих зон.

Оценка эффективности медпредставителей: Отслеживание выполнения планов (KPI) конкретными сотрудниками.

Анализ по брендам: Динамика продаж препаратов, выявление самых популярных и быстрорастущих продуктов.

Сравнение команд: Оценка работы разных команд продаж и их вклада в общий результат.

Технологический стек:

Power BI (создание модели данных, DAX-меры, интерактивные визуализации).

Источники данных: Excel.
