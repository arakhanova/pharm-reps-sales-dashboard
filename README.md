# Анализ продаж фармацевтической компании по территориям, брендам и командам продаж.

## 📖 О проекте
Данный проект представляет собой интерактивный аналитический дашборд, разработанный в **Power BI** для анализа продаж фармацевтической компании. 

Инструмент ориентирован на **региональных менеджеров** и **директоров по маркетингу**, позволяя в реальном времени оценивать эффективность работы медицинских представителей, анализировать продажи по территориям, брендам и командам. 

Для наполнения дашборда использованы **синтетические данные**, которые имитируют реальные бизнес-процессы. Они не содержат конфиденциальной информации, но при этом описывают абсолютно реальные рабочие ситуации и задачи, стоящие перед отделами продаж в фармацевтике.

## 🎯 Задача
Визуализация и анализ продаж по территориям, брендам и командам медицинских представителей.

## ⚙️ Реализация
Построение модели данных в Power BI, написание мер на языке DAX, создание интерактивных отчетов с возможностью фильтрации.

## 🚀 Результат
Создан инструмент, позволяющий руководству быстро оценивать эффективность полевых сил (field force) и принимать решения на основе данных (data-driven decisions).

## 💡 Ключевые возможности дашборда

*   **🗺️ Анализ по территориям:** Сравнение показателей продаж в разных регионах, выявление лидеров и отстающих зон.
*   **🏆 Оценка эффективности медпредставителей:** Отслеживание выполнения планов (KPI) конкретными сотрудниками.
*   **💊 Анализ по брендам:** Динамика продаж препаратов, выявление самых популярных и быстрорастущих продуктов.
*   **🤝 Сравнение команд:** Оценка работы разных команд продаж и их вклада в общий результат.

## 🛠️ Технологический стек

*   **Power BI** (создание модели данных, DAX-меры, интерактивные визуализации).
*   **Источники данных:** Excel.

## 💡 Рекомендации по результатам анализа

На основе данных дашборда можно сформулировать следующие шаги для руководства:

1.  **Маркетинг и продвижение (Фокус на проблемные бренды):**
    *   **Лактогель:** У бренда наихудший рейтинг среди врачей и максимальное падение продаж (-7,1 млн). Рекомендуется пересмотреть стратегию продвижения (обновить CLM-материалы, провести дополнительное обучение МП по аргументации) или запустить программу лояльности для врачей.
    *   **Тозин и Неокр:** Требуется детальный анализ причин невыполнения плана (возможно, проблемы с поставками или действиями конкурентов).

2.  **Работа с территориями:**
    *   **«Титульная» и «Историческая» области:** Это главные «зоны риска» (-4 млн руб. в сумме). Необходимо провести аудит работы местных команд и, возможно, перераспределить ресурсы или усилить поддержку со стороны маркетинга.
    *   **«Приморская область»:** При низких продажах важно понять, это проблема покрытия (мало аптек) или низкой активности МП.

3.  **Управление полевыми силами (HR и KPI):**
    *   **Беляева Анна:** Показала наихудший индекс соответствия стратегии (71,6%) и сильное отставание по визитам (-15%). Рекомендуется индивидуальная работа с руководителем: выяснить причины (выгорание, нехватка знаний, проблемы с территорией).
    *   **Габрашилова Наиля:** Показала лучший результат (82,3%). Можно использовать её опыт как пример для обучения остальных сотрудников (наставничество).
    *   **Визиты с CLM (74%):** Показатель хороший, но есть куда расти. Увеличение доли визитов с CLM напрямую влияет на индекс соответствия стратегии.

4.  **Аптечный канал:**
    *   **Сеть «Цветок»:** Имеет отрицательное обеспечение товаром (-15,3%). Высок риск out-of-stock (отсутствия товара на полке). Нужно срочно наладить коммуникацию с закупщиками сети.
    *   **Неликвиды (0,65%):** Показатель низкий (это хорошо), но стоит держать на контроле товары с истекающим сроком годности, чтобы не допустить списаний.
